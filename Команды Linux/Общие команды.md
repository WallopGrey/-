- `ls` — показывает содержимое текущей директории, кроме скрытых файлов
- `ls -a` — показывает всё содержимое, включая скрытые файлы
- `ls -l` — подробный список: права, владелец, группа, размер, дата изменения
- `ls -d` — показывает информацию **о самой директории**, а не её содержимом
- `chmod` — изменение прав доступа к файлу или директории
- `chown` — изменение владельца и/или группы файла или директории

mkdir` — создание директории
mkdir -p — создание директории вместе с вложенными директориями 
rmdir — удаление пустой директории

useradd — создание пользователя
passwd — установка/изменение пароля пользователя
usermod — изменение параметров пользователя
userdel — удаление пользователя

groupadd — создание группы
groupdel — удаление группы
usermod -aG — добавление пользователя в группу
groups — показывает группы пользователя

ps — информация о процессах
top — просмотр процессов в реальном времени
kill — завершение процесса
systemctl — управление службами

ip a — информация о сетевых интерфейсах и IP
ping — проверка доступности узла
ssh — подключение к удалённому компьютеру

apt update — обновление списка пакетов
apt upgrade — обновление установленных пакетов
apt install — установка пакета
apt remove — удаление пакета

docker ps — запущенные контейнеры
docker ps -a — все контейнеры
docker images — список образов

docker build — создание Docker-образа
docker run — запуск контейнера
docker stop — остановка контейнера
docker start — запуск остановленного контейнера
docker rm — удаление контейнера

docker logs — просмотр логов контейнера
docker exec — выполнение команды внутри контейнера

docker network create — создание Docker-сети
docker network ls — список Docker-сетей
