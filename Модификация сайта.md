Текущая проблема: кол-во посетителей не соответствует действительности.

Место проявления проблемы: Nginx&FrontEnd 

Анализ проблемы: При использовании одного IP адреса: Nginx засчитает каждое посещение как новое 

Решение: Закрепление IP адреса, путем сравнения по базе

Тестирование: 
1)с помощью другого ноутбука/техники (но только один раз)
2)с помощью Docker (можно многократно). Создаем контейнеры с уникальными IP адресами и делаем CURL-запросы.
